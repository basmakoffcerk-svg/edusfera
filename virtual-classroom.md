# Концепция виртуального класса Edusfera

Это базовое описание концепции виртуального класса, интегрированного в экосистему Edusfera.

## 🌟 Основная идея
Виртуальный класс должен представлять собой набор независимых микросервисов, подключаемых к платформе через **универсальный API-шлюз (API Gateway)**. Это позволит развивать и масштабировать каждый компонент (видеосвязь, интерактивная доска, ИИ) независимо друг от друга.

## 🛠️ Функциональные блоки
1. **Видеозвонок:** Работает на мощностях платформы. Реализуется на высокопроизводительном языке (Go/Rust) с максимальной оптимизацией под слабые каналы связи (1–2 Мбит/с при SD-качестве).
2. **Интерактивная доска (Workspace):** Полноценное рабочее пространство (канбан-доска), открывающееся по кнопке в правом верхнем углу.
   - Поддерживает создание готовых встроенных блоков (текстовые заметки, списки задач, изображения, код-фреймы, таймеры).
   - Интегрирует ИИ-агента для создания блоков по текстовому описанию (например, *"создай чек-лист подготовки к ЦТ"*).
3. **Вездесущий ИИ-ассистент:** Глобальный ИИ-помощник, интегрированный во все разделы платформы (доступен из любого меню для контекстных ответов).
4. **Хранилище и тарифная сетка:**
   - Каждому пользователю при регистрации выделяется **2 ГБ** дискового пространства.
   - Расширение памяти и полный функционал ИИ предоставляются по подписке (тариф Pro).
