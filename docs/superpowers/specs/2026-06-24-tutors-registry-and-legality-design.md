# Спецификация: Перепозиционирование Edusfera под Госреестр репетиторов с 1 июля

Этот документ описывает изменения на промо-странице `public/promo/index.html` платформы Edusfera.by в связи с запуском государственного реестра репетиторов в Беларуси с 1 июля.

## 1. Описание задачи и цели
С 1 июля 2026 года в Беларуси запускается государственный реестр репетиторов. Деятельность вне реестра признается незаконной и влечет за собой крупные штрафы и конфискацию доходов.
Текущий лендинг позиционирует платформу как «выгоднее репетитора в чёрную», борясь с несуществующим с 1 июля рынком «черных репетиторов». 

**Цель**:
- Изменить позиционирование: фокус на легальность, безопасность (100% репетиторов в реестре), защиту от штрафов и отмен.
- Показать ценность платформы для репетиторов (помощь со вступлением в реестр, автоматизация чеков и уплаты налога на профдоход — НПД).
- Заменить дешевую форму бета-теста Google Forms (iframe) на высококонверсионную встроенную HTML/JS форму в стиле Glassmorphism.
- Обновить сравнения в калькуляторе и секцию FAQ под новые правовые реалии.

## 3. Требования к безопасности и качеству (Security & Hardening)
1. **Санитаризация данных (XSS Prevention)**:
   При выводе имени пользователя в сообщении об успехе имя должно быть экранировано с помощью функции безопасного текстового вывода, чтобы злоумышленник не мог ввести `<script>alert(1)</script>` в поле имени.
   ```javascript
   function escapeHTML(str) {
     return str.replace(/[&<>"']/g, function(m) {
       switch (m) {
         case '&': return '&amp;';
         case '<': return '&lt;';
         case '>': return '&gt;';
         case '"': return '&quot;';
         case "'": return '&#039;';
         default: return m;
       }
     });
   }
   ```
2. **Валидация телефона**:
   Телефон должен соответствовать белорусскому формату (начинаться с `+375` и содержать 9 цифр кода и номера).
3. **Мобильная адаптивность**:
   Все новые элементы формы и информационные карточки должны корректно перестраиваться на мобильных экранах (от 320px до 768px), сохраняя пропорции и читаемость.

## 4. План тестирования
- **Визуальный контроль**: Проверка отображения на десктопных и мобильных разрешениях.
- **Интерактив формы**: Проверка валидации пустых полей, некорректного формата телефона.
- **Имитация отправки**: Проверка появления экрана успеха, сохранения данных в `localStorage` и экранирования спецсимволов в имени.
- **Калькулятор**: Проверка корректности пересчета сумм и изменения подписей при переключении режима «Родитель»/«Репетитор».
