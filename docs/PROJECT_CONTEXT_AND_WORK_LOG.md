## 1. Архитектурный стек и инфраструктура

- **Backend:** Laravel 11.x, PHP 8.3+, MySQL 8.0, Redis Streams (шина событий).
- **Admin & Dashboards:** Filament PHP 3.x (кабинеты Репетитора, Ученика, Родителя, Суперадминистратора).
- **Frontend & Reactivity:** Livewire 3, Alpine.js 3, Vanilla CSS с палитрой Glassmorphism / 8pt Grid.
- **Видеосвязь и виртуальный класс:** LiveKit Cloud / Self-hosted WebRTC, Coturn (STUN/TURN), Excalidraw (интерактивная доска).
- **Искусственный интеллект:** Edusfera AI (собственная мультимодальная нейросетевая архитектура и ассистенты платформы).
- **Платежи и фискализация:** Alfa-Bank API (эквайринг BYN), чеки НПД (МНС Республики Беларусь).
- **Схема доставки кода (Zero-Downtime Patch):**
  - Сборка: `bash scripts/make-patch.sh` (формирует легковесный `edusfera-patch.zip`).
  - Доставка: `curl -s -k -F "patch_file=@edusfera-patch.zip" "https://edusfera.by/migrate.php?key=edusfera2026&action=upload_patch"`
  - Сброс кэша Laravel: автоматический через `migrate.php` (`config:clear`, `cache:clear`, `route:clear`, `view:clear`).

## 2. Маршрутизация Google Gemini AI через xbox-dns.ru (Обход гео-блокировки)

### Проблема
Прямые вызовы Google Gemini API с белорусского IP сервера `176.60.210.120` блокировались Google:  
`User location is not supported for the API use`.

### Архитектурное решение
Использован Smart DNS / SNI-прокси сервис `xbox-dns.ru`:
1. Домен `generativelanguage.googleapis.com` перенаправляется на европейские SNI-прокси узлы:
   - `188.68.214.130`
   - `188.68.214.143`
2. **Без изменений в ОС:** Запросы перенаправляются на уровне PHP/Guzzle через cURL-опцию `CURLOPT_RESOLVE`, поэтому не требуется менять `/etc/resolv.conf` или поднимать сторонний VPN на хосте.
3. **Безопасность TLS:** Соединение сквозное по TLS (SSL-сертификат Google верифицируется без подмены, `SSL certificate verify ok`).
4. **Отказоустойчивость:**
   - Динамический DoH-резолвинг (`https://xbox-dns.ru/dns-query`) с кэшированием на 30 минут и статическим fallback-пулом.
   - Быстрый таймаут соединения (`CURLOPT_CONNECTTIMEOUT = 4s`) для мгновенного переключения узлов при просадке сети.
   - Каскадный fallback моделей: `gemini-3.5-flash-lite` ➔ `gemini-flash-latest` (защита от временных 503 ошибок пиковой нагрузки Google).

### Измененные файлы:
- `config/services.php`: добавлен флаг `'use_xbox_dns' => env('GEMINI_USE_XBOX_DNS', true)`.
- `app/Services/Ai/GeminiService.php`:
  - Метод `applyHttpOptions()` с инжекцией `CURLOPT_RESOLVE`.
  - Методы `getXboxDnsIps()`, `buildDnsQueryPacket()`, `parseDnsResponseIps()`.
  - Улучшен `testConnection()` с каскадным перебором моделей.
- `public/migrate.php`: добавлены экшены `action=test_ai` и `action=test_xbox_dns`, а также тумблер в форме настроек Gemini.

### Результат проверки на боевом сервере:
- Задержка первого запроса: **~930–1060 мс**.
- Генерация ответа: **~0.98 сек**.
- Статус: **100% УСПЕШНО**.

## 3. Продвинутый ИИ-Ассистент платформы (Edusfera Copilot & Методист)

Плавающий интеллектуальный агент для кабинетов репетитора и ученика.

### Возможности и архитектура:
1. **Бэкенд (`app/Http/Controllers/AiCopilotController.php`)**:
   - Ролевые персоны (`persona`):
     - `rikz_expert`: Эксперт-составитель тестов ЦТ/ЦЭ 2026 (РИКЗ), поиск ловушек и капканов в заданиях.
     - `express_solver`: Экспресс-решатель задач (строгие формулы, пошаговые вычисления, итоговый ответ).
     - `simple_analogy`: Мастер педагогических аналогий (объяснение сложных тем "на пальцах").
     - `homework_gen`: Генератор домашних заданий с критериями проверки и ключами.
     - `methodologist`: Педагогический методист уроков (технологические карты, тайминг).
     - `free_chat`: Свободный диалог.
   - Настройка тона (`tone`): академический, дружелюбный, предельно краткий, пошаговый.
   - Настройка объема (`length`): краткий конспект, сбалансированный, подробный разбор.
   - Поддержка индивидуального пользовательского промпта (`custom_prompt`).

2. **Фронтенд-интерфейс (`resources/views/partials/ai-copilot-widget.blade.php`)**:
   - **Visuals & Aurora Glassmorphism:** Живой анимированный нейро-аватар (Orb) с аурой дыхания, гипер-свечением при генерации и визуализацией звуковой волны.
   - **Живой Typewriter:** Потоковая симуляция печати ответа с мерцающим фиолетовым карет-курсором.
   - **Голосовой ввод (Speech-to-Text STT):** Кнопка микрофона с неоновым пульсирующим кольцом для диктовки запросов без клавиатуры.
   - **Синтез речи (Text-to-Speech TTS):** Озвучивание ответов голосом на русском языке с кнопкой паузы.
   - **Web Audio API:** Нежные звуковые микро-клики при отправке сообщения и завершении генерации (отключаемые).
   - **Режим Maximize (⤢):** Разворачивание виджета на широкий экран для удобного чтения больших планов и тестов.
   - **Шторка настроек (⚙️):** Настройка персоны, тональности, объема, звуков и автосохранение предпочтений в `localStorage`.
   - **Инструменты экспорта:** Быстрое копирование в буфер, скачивание конспекта в `.md` файл.

## 4. Виртуальный класс и интерактивная доска (LiveKit + Excalidraw)

- **Интеграция LiveKit:** Видео и аудио высокого качества с автоматической подстройкой битрейта (Dynacast), поддержкой Safari/iOS Autoplay policy и fallback на TURN-серверы Metered.
- **Интерактивная доска:** Excalidraw, встроенная через безопасный изолированный контейнер с двусторонней синхронизацией объектов доски в реальном времени.
- **Мобильный UX:**
  - Glassmorphism Action Sheet и портретный режим управления.
  - Полноэкранный режим с плавающим Picture-in-Picture окном собеседника.
  - Поддержка сенсорных жестов (pinch-to-zoom, панорамирование).
- **ИИ прямо на уроке (`ClassroomController::chatAi`, `AiService.php`)**:
  - Распознавание команд в чате урока ("создай дз", "зафиксируй пробел", "сохрани в конспект").
  - Автоматическое создание сущностей в БД: назначение домашнего задания, фиксация пробелов (`SkillGap`), создание учебных целей (`StudentGoal`).
  - Сохранение полной истории ИИ-диалога урока в метаданных сессии (`activeClassroom->meta['ai_chat_history']`).

## 7. Модель чистого бронирования из каталога (Direct Booking Model)

### Изменения в процессе записи:
1. **Исключение онлайн-оплаты при бронировании:**
   - В `LessonBookingController` исключен редирект на экран оплаты `checkout.show` и списание с кошелька.
   - Ученик бронирует слот (или пакет) и сразу получает подтверждение на странице репетитора с возможностью перейти в кабинет.
2. **Фиксация слотов без авто-отмены:**
   - В `BookingService` снят 15-минутный таймер (`payment_lock_expires_at = null`). Слот сразу фиксируется за учеником со статусом `pending` и блокируется от повторного бронирования другими пользователями.
3. **Нативные уведомления репетитору:**
   - `LessonBookedTutorNotification` интегрирован с `FilamentNotification::make()`: мгновенно отображается в колокольчике панели управления со ссылкой на `/admin/lesson-requests`.
   - В email-уведомление добавлены имя, телефон ученика, комментарий к уроку, выбранный пакет и прямая кнопка перехода к заявке.
4. **UX и микрокопия:**
   - В карточке репетитора (`catalog/show.blade.php`) обновлены бейджи («Удобная бронь»), выбор формата («Формат занятий»), условия («Оплата напрямую преподавателю») и стильный баннер подтверждения.
